# MovieMate
a smart movie recommendation program.
The Movie Recommendation Program is a C++-based application designed to help users discover movies according to their interests. The program allows users to select a preferred genre and enter a minimum rating out of 10. Based on these inputs, it searches the movie database and displays matching movies along with their titles, genres, ratings, and release years.
The project uses Object-Oriented Programming (OOP) concepts such as classes, objects, constructors, and encapsulation to organize movie data. It also incorporates Data Structures and Algorithms (DSA) concepts, including vectors, searching, filtering, and sorting, to manage movie records and generate suitable recommendations.
The application provides a simple, user-friendly, terminal-based interface. Its main objective is to demonstrate the practical use of C++ programming, OOP, and DSA to solve a real-world problem and make movie selection easier and more efficient.
